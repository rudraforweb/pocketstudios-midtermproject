Overview

Pocket Studios is an innovative digital media and game design company that develops creative, high-quality content. The studio emphasizes teamwork, secure data management, and modern network infrastructure to support its daily operations.

Software

Pocket Studios has access to the full Microsoft 365 suite. It is a Software as a Service (SaaS) solution. It enables employees to collaborate efficiently by allowing real-time editing, file sharing, and communication across applications. This enables access to Word, Excel, PowerPoint, Teams, OneDrive, etc. We also use Windows Defender, a free and secure antivirus to make sure our PCs are safe.

Hardware

We have access to high quality gaming PCs, the NZXT Player Two, for game design and digital media. It is perfect for resource-hungry tools like Visual Studio and Blender. They can also run Adobe for digital media. Since the PCs run Windows, they integrate easily with the Microsoft 365 suite. We also have 4K Alienware monitors for high-resolution display while being buttery smooth. We also have the Espon EcoTank for printing documents and images while being environmentally friendly.

Networking

We use a secure, high-speed network infrastructure to facilitate seamless communication and data transfer between all devices and systems.
• Cloud0: This represents the ISP, AT&T Business Fiber WiFi.
• Router4: This is the router, the Netgear CAX80.
• Firewall: This is the firewall, the Firewalla Purple.
• Switch1: This is the switch, the TP-Link TL-SG1024.
• Hub0: This is the network hub for the Game Design department.
• Hub1: This is the network hub for the Digital Media department.
• Printer0: This is the company printer, the Epson EcoTank.
• GD-C1 to GD-C5: These are employee PCs for the Game Development department.
• DM-C1 to DM-C5: These are employee PCs for the Digital Media department.
